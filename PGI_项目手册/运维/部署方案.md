# 部署方案

本文档详细阐述 PGI 系统的本地开发环境、Docker 生产部署、构建命令、ChromaDB 启动、SQL 导入、配置文件体系和启动检查清单。适合实施人员和运维人员理解"怎么把系统跑起来"。

## 一、本地开发环境

### 1.1 环境要求

| 组件 | 版本 | 用途 | 说明 |
|------|------|------|------|
| JDK | **21** | 后端编译运行 | OpenJDK 21 LTS |
| Maven | 3.9+ | 后端构建 | 项目未内置 mvnw |
| MySQL | 8.0 | 业务数据库 | 8.4 也可 |
| Redis | 7.x | 缓存/Session/Token | 7-alpine 即可 |
| ChromaDB | latest | 向量数据库（RAG） | Docker 或 Python |
| Node.js | 20+ | 前端构建 | LTS 版本 |
| IDEA | 推荐 | 后端 IDE | Ultimate 或 Community |

### 1.2 关键配置位置

| 配置文件 | 内容 |
|----------|------|
| `ruoyi-admin/src/main/resources/application.yml` | 主配置（端口 8080, Redis, MyBatis, Token, XSS） |
| `application-druid.yml` | 数据源（MySQL pgi 库） |
| `application-ai.yml` | AI 模块（DeepSeek + ChromaDB + 业务参数） |

### 1.3 本地连接参数（默认）

| 组件 | 地址 | 认证 |
|------|------|------|
| MySQL | localhost:3306 | root / 你的密码 |
| Redis | localhost:6379 | 你的密码, database 4 |
| ChromaDB | 127.0.0.1:8000 | 无 |
| 后端 | http://localhost:8080 | — |
| 前端 | http://localhost:80 | admin/admin123 |

## 二、Docker 生产部署

### 2.1 docker-compose 服务编排

`deploy/docker-compose.yml` 定义 5 个服务：

| 服务 | 镜像 | 端口 | 依赖 | 说明 |
|------|------|------|------|------|
| **mysql** | mysql:8.0 | 3306 | — | 自动导入 SQL |
| **redis** | redis:7-alpine | 6379 | — | — |
| **chroma** | chromadb/chroma:latest | 8000 | — | 向量数据库 |
| **app** | Spring Boot JAR | 8080 | mysql / redis / chroma | 后端应用 |
| **nginx** | nginx:alpine | 80 | app | 前端静态资源 |

### 2.2 一键启动

```bash
cd deploy
docker-compose up -d
```

### 2.3 Nginx 配置要点

- 反向代理 `/prod-api` → `app:8080`
- 前端静态资源服务
- **SSE 缓冲关闭**（`proxy_buffering off`）— 流式对话必须

```nginx
server {
    listen 80;
    server_name localhost;

    # 前端静态资源
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /prod-api/ {
        proxy_pass http://app:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;

        # SSE 必须关闭缓冲
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 3600s;
    }
}
```

### 2.4 Dockerfile

**后端镜像**（`Dockerfile.backend`）：
```dockerfile
FROM eclipse-temurin:21-jre
WORKDIR /app
COPY ruoyi-admin/target/ruoyi-admin.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

**前端镜像**（`Dockerfile.frontend`）：
```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY ruoyi-ui/RuoYi-Vue3 .
RUN npm install && npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY deploy/docker/nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

## 三、构建命令

### 3.1 后端

```bash
# 编译打包（跳过测试）
mvn install -DskipTests

# 运行
java -jar ruoyi-admin/target/ruoyi-admin.jar

# 指定端口
java -jar ruoyi-admin/target/ruoyi-admin.jar --server.port=9090
```

### 3.2 前端

```bash
cd ruoyi-ui/RuoYi-Vue3

# 安装依赖（淘宝镜像加速）
npm install --registry=https://registry.npmmirror.com

# 开发
npm run dev

# 生产构建
npm run build

# 预览生产构建
npm run preview
```

## 四、ChromaDB 启动

### 4.1 方式 A：Docker（推荐）

```bash
docker run -d -p 8000:8000 --name chromadb chromadb/chroma:latest
```

验证启动成功：

```bash
curl http://localhost:8000/api/v1/health
# 返回 {"heartbeat": ...} 即正常
```

### 4.2 方式 B：Python 本地

适合没有 Docker 的环境：

```bash
# 确保已安装 Python 3.9+
python --version

# 安装 ChromaDB
pip install chromadb

# 启动服务
chroma run --host 127.0.0.1 --port 8000 --path "D:/chroma_data"
```

> 提示：可写一个 bat 启动脚本一键启动，参考 `deploy/start_chroma.bat`。

### 4.3 确认 ChromaDB 配置

打开 `ruoyi-admin/src/main/resources/application-ai.yml`：

```yaml
spring:
  ai:
    vectorstore:
      chroma:
        client:
          host: http://localhost
          port: 8000
        collection-name: pgi_knowledge
        initialize-schema: true
```

一般不需要修改。ChromaDB 启动后会自动创建 `pgi_knowledge` 集合。

## 五、SQL 导入

### 5.1 建库

```sql
CREATE DATABASE IF NOT EXISTS pgi
DEFAULT CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

### 5.2 导入顺序

按顺序执行：

```sql
-- 1. RuoYi 系统表 + 初始化数据
source sql/ry_20260417.sql;

-- 2. Quartz 定时任务表
source sql/quartz.sql;

-- 3. 菜单权限初始化
source sql/pgi_menu.sql;

-- 4. 字典数据初始化
source sql/dict_init.sql;
```

### 5.3 SQL 文件说明

| 文件 | 说明 | 必须执行 |
|------|------|---------|
| `ry_20260417.sql` | RuoYi 系统表 DDL + 初始化数据（用户/角色/菜单/字典） | ✅ |
| `quartz.sql` | Quartz 定时任务表 | ✅ |
| `pgi_menu.sql` | 菜单权限初始化（80+ 菜单项 + 角色关联） | ✅ |
| `dict_init.sql` | 字典数据初始化（pgi_* 系列字典） | ✅ |
| `test_data.sql` | 测试数据 | 可选 |
| `cleanup_generator_orphan.sql` | 代码生成器残留清理 | 仅旧库升级，全新库不执行 |

> [!warning] 注意
> `cleanup_generator_orphan.sql` 仅旧库升级用（清理代码生成器残留），**全新数据库请勿执行**，否则可能误删数据。

## 六、配置文件体系

### 6.1 后端配置

| 配置文件 | 内容 | Profile |
|----------|------|---------|
| `application.yml` | 主配置（端口 8080, Redis, MyBatis, Token, XSS） | 默认 |
| `application-druid.yml` | 数据源配置（MySQL pgi 库） | druid |
| `application-ai.yml` | AI 模块配置（DeepSeek + ChromaDB + 智谱 embedding + 业务参数） | ai |

`application.yml` 中：
```yaml
spring:
  profiles:
    active: druid       # 激活数据源
    include: ai         # 包含 AI 模块
```

### 6.2 application-druid.yml 关键配置

```yaml
spring:
  datasource:
    type: com.alibaba.druid.pool.DruidDataSource
    driverClassName: com.mysql.cj.jdbc.Driver
    druid:
      master:
        url: jdbc:mysql://localhost:3306/pgi?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
        username: root
        password: 你的MySQL密码
      slave:
        enabled: false
      # 连接池配置
      initialSize: 5
      minIdle: 10
      maxActive: 20
      maxWait: 60000
```

### 6.3 application-ai.yml 关键配置

```yaml
spring:
  ai:
    openai:
      base-url: https://api.deepseek.com
      api-key: ${DEEPSEEK_API_KEY:your-api-key-here}
      chat:
        options:
          model: deepseek-chat
          temperature: 0.7
          max-tokens: 4096
    vectorstore:
      chroma:
        client:
          host: http://localhost
          port: 8000
        collection-name: pgi_knowledge
        initialize-schema: true

# 智谱 embedding 配置
zhipu:
  api-key: ${ZHIPU_API_KEY:your-zhipu-key}
  base-url: https://open.bigmodel.cn/api/paas/v4/
  embedding-model: embedding-2

# AI 业务参数
rag:
  chunk:
    size: 500
    overlap: 50
  embedding:
    batch-size: 20
    retry-limit: 3
  retrieval:
    top-k: 5
```

### 6.4 前端配置

| 配置文件 | 内容 |
|----------|------|
| `.env.development` | `VITE_APP_BASE_API=/dev-api` |
| `.env.production` | `VITE_APP_BASE_API=/prod-api` + gzip |
| `vite.config.js` | 端口 80，代理 `/dev-api` → `http://localhost:8080` |

## 七、跳过 AI 模块启动

> 如果暂时不需要 AI 功能，可跳过 ChromaDB 和 DeepSeek。

```yaml
# application.yml
spring:
  profiles:
    active: druid
    # include: ai    # 注释掉，跳过 AI 模块
```

这样后端不依赖 ChromaDB 和 DeepSeek，可先跑通基础招标功能。

## 八、文件上传路径配置

系统默认上传文件保存目录在 `application.yml` 中配置：

```yaml
ruoyi:
  profile: D:/ruoyi/uploadPath    # Windows
  # profile: /home/ruoyi/uploadPath    # Linux
```

后续可集成云存储（OSS/COS）。

## 九、Token 密钥配置

`application.yml` 中 `token.secret` 默认为弱密钥，**生产环境务必修改**：

```yaml
token:
  header: Authorization
  secret: 请替换为一串足够长的随机字符串
  expireTime: 30    # 分钟
```

## 十、启动检查清单

| # | 检查项 | 状态 |
|---|--------|------|
| 1 | MySQL 已启动，数据库 `pgi` 已创建，SQL 已导入 | ☐ |
| 2 | Redis 已启动（6379 端口） | ☐ |
| 3 | ChromaDB 已启动（8000 端口） | ☐ |
| 4 | `application-druid.yml` MySQL 密码已修改 | ☐ |
| 5 | `application.yml` Redis 密码已修改 | ☐ |
| 6 | `application-ai.yml` DeepSeek API Key 已配置（可选） | ☐ |
| 7 | IDEA 已设置 JDK 21 并加载完 Maven 依赖 | ☐ |
| 8 | 前端 `npm install` 已完成 | ☐ |
| 9 | 后端 `RuoYiApplication` 启动无报错 | ☐ |
| 10 | 前端 `npm run dev` 可访问登录页 | ☐ |

## 十一、部署脚本

`deploy/scripts/` 目录提供运维脚本：

| 脚本 | 用途 |
|------|------|
| `startup.sh` | 启动：`docker-compose up -d` |
| `shutdown.sh` | 停止：`docker-compose down` |
| `backup.sh` | 备份：mysqldump + redis rdb |
| `deploy.sh` | 部署：构建镜像 → 推送 → 滚动更新 |

## 十二、环境变量

生产环境建议通过环境变量注入敏感信息：

| 环境变量 | 用途 |
|---------|------|
| `DEEPSEEK_API_KEY` | DeepSeek API Key |
| `ZHIPU_API_KEY` | 智谱 API Key |
| `MYSQL_PASSWORD` | MySQL 密码 |
| `REDIS_PASSWORD` | Redis 密码 |
| `TOKEN_SECRET` | JWT 密钥 |
