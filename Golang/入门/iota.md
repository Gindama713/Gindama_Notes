1. **`iota` 是 const 块中的行号，从 0 开始，每新增一行常量声明就自动加 1。**  
    注意：是“每一行”，哪怕这一行没有用到 `iota`，它也会加 1。
2. **如果某一行没有写 `= 表达式`，它就完全照抄上一行的表达式（包括 `iota`），但 `iota` 的值是当前行的值。**
```go
const (
    a = iota   // 第 0 行，iota = 0
    b          // 第 1 行，iota = 1
    c          // 第 2 行，iota = 2
    d = "ha"   // 第 3 行，iota = 3
    e          // 第 4 行，iota = 4
    f = 100    // 第 5 行，iota = 5
    g          // 第 6 行，iota = 6
    h = iota   // 第 7 行，iota = 7
    i          // 第 8 行，iota = 8
)
```
