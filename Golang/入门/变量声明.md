

在 Go 中，声明变量但未赋值时，会自动赋予该类型的零值：

- `int` → `0`
- `float64` → `0`
- `bool` → `false`
- `string` → `""`（空字符串）
    

所以：


```go
var i int       // i = 0
var f float64   // f = 0
var b bool      // b = false
var s string    // s = ""
```
### 2. `%v` 和 `%q` 的含义

`fmt.Printf` 的第一个参数是格式字符串，里面的 `%` 开头的叫“动词”，用来指定后面参数的输出格式。

- **`%v`**：通用默认格式。它会根据值的类型自动选择合适的表示方式。
    
    - `int` → `0`
    - `float64` → `0`
    - `bool` → `false`
    - `string` → 直接输出字符串内容（空字符串就什么也看不见）
        
- **`%q`**：用于输出**带引号的字符串**（或字符）。
    
    - 对字符串：输出双引号括起来的、转义后的字符串。
        
    - 对整数：输出单引号括起来的字符字面量（如 `'A'`）。  
        这里 `s` 是字符串，所以 `%q` 会把空字符串显示为 `""`，让你能明确看到它是一个空字符串，而不是一片空白。
        

- `%v`：按默认格式输出任何类型的值，适合快速查看。
- `%q`：专门用于字符串（或字符），输出带引号的转义形式，便于观察空字符串、特殊字符（如 `\n`、`\t`）等。
- 这段代码用 `%v` 展示 int float bool 的零值，用 `%q` 展示 string 的零值 `""`，是一个很典型的 Go 零值演示。

```go
package main  
import "fmt"  
  
// 定义性别枚举  
const (  
    Unknown = 0  
    Female  = 1  
    Male    = 2  
)  
  
func main() {  
    fmt.Printf("未知=%d, 女性=%d, 男性=%d\n", Unknown, Female, Male)  
}
```
