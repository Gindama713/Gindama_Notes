
**Redis 是一个基于内存的高性能 Key-Value 数据库。**
**Redis 就是一个“超快的临时仓库”，主要用来做缓存、存会话、限流、做消息队列。**

| 特点               | 说明                                  |
| ---------------- | ----------------------------------- |
| **内存存储**         | 数据放内存，读写极快                          |
| **Key-Value 结构** | 一个 key 对应一个 value                   |
| **多种数据类型**       | String、Hash、List、Set、ZSet           |
| **持久化**          | 可以定期把内存数据存到硬盘，防丢                    |
| **单线程**          | 核心命令单线程执行，避免锁竞争，反而快                 |
| **支持过期**         | 可以给 key 设置 TTL（Time To Live），到期自动删除 |

## Redis 的常见用途

| 用途           | 说明            | 例子                   |
| ------------ | ------------- | -------------------- |
| **缓存**       | 最常用，减轻数据库压力   | 商品详情、用户信息            |
| **会话管理**     | 存用户登录态        | Session、JWT 黑名单      |
| **限流**       | 控制请求频率        | LLM Gateway 每分钟 20 次 |
| **Token 统计** | 累加用户消耗        | AI Gateway 统计 token  |
| **多轮对话记忆**   | 存对话历史         | 短期记忆                 |
| **分布式锁**     | 多服务互斥         | 防止重复下单               |
| **排行榜**      | ZSet 天然支持     | 游戏积分榜                |
| **消息队列**     | List / Stream | 简单异步任务               |

**你之前问的 LLM Gateway，限流和 Token 统计就是 Redis 的经典用法。**

## Redis 的 5 种基本数据类型

| 类型         | 结构              | 典型用途            |
| ---------- | --------------- | --------------- |
| **String** | key → 字符串       | 缓存、计数器、Token 统计 |
| **Hash**   | key → {字段: 值}   | 存对象，如用户信息       |
| **List**   | key → 有序列表      | 消息队列、最新列表       |
| **Set**    | key → 无序集合      | 去重、标签、共同好友      |
| **ZSet**   | key → 有序集合（带分数） | 排行榜、延迟队列        |
**所以：Redis 存热点、存临时、存会话；MySQL 存核心业务数据。**
