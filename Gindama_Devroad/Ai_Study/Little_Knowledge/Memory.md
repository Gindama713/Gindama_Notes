**是什么**：把历史对话内容**塞进当前 prompt**，让 LLM 在回答时能看到之前的对话。

**怎么工作**：

```
[历史对话 + 系统提示词 + 当前问题]
            ↓
       打包成一个完整 prompt
            ↓
         喂给 LLM
            ↓
       LLM 基于这些信息回答
```

**两种实现方式**：

| 方式 | 说明 | 缺点 |
|---|---|---|
| 全量塞 | 把所有历史对话都塞 prompt | 长对话会撑爆上下文窗口 |
| 摘要塞 | 只保留摘要 + 关键事实 | 会丢细节 |

**例子（OpenClaw 的做法）**：
- 每次会话开头我会读 `MEMORY.md` + `memory/YYYY-MM-DD.md`
- 这些文件里有"姜苏豪""蓝桥杯国一""讨厌客气"这些关键信息
- 我回答时**临时读到**这些信息——**不是真的"记住了"**
