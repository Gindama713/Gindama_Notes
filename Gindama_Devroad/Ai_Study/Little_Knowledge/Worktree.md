`worktree` 全称 **Git Worktree**，是 Git 的一个原生命令[](https://www.kernel.org/pub/software/scm/git/docs/git-worktree.html)。它允许你在**同一个 Git 仓库**里，同时检出**多个不同的分支**到**不同的文件夹**中。

- **共享底层**：所有房间（worktree）共享同一个地基、水电系统（即 `.git` 目录里的提交历史、分支信息）。
- **独立空间**：每个房间（worktree）都有自己独立的家具和装修（即工作目录里的文件），互不干扰。

这样你就能在“客厅”开发新功能的同时，在“书房”紧急修复 Bug，而无需来回切换分支或复制整个项目

- [[LangGraph]] 是“**大脑**”：它决定要拆几个任务，要不要并行。
- **Worktree** 是“**沙盒**”：它负责给每个并行的任务提供一块独立的物理地盘。
- **Agent** 是“**工人**”：在自己的沙盒里干活。
