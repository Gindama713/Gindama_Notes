一个完整的 Harness 通常包含以下几个关键部分

- **工具调用 (Tools)**：给模型“双手”，让它能操作文件、终端、浏览器等。
- **观察与反馈 (Observation)**：给模型“眼睛”，能查看代码运行结果、报错信息。
- **记忆管理 (Memory)**：给模型“海马体”，管理长任务中的上下文和状态。
- **规划与调度 (Planning)**：将复杂任务拆解为子步骤，并决定执行顺序。
- **权限与护栏 (Guardrails)**：设定安全边界，如沙箱执行、危险操作前需人工审批。

- **与 [[LangGraph]]： 是构建 Harness 的一种工具或框架**。Harness 是更宏观的概念，而 LangGraph 提供了实现状态机、循环等复杂控制流的编程模型。
- **与 [[MCP]]/[[ToolUse_FunctionCalling]]：**MCP 和 Tool Calling 是 Harness 的“工具调用”模块的具体实现标准**。它们解决了 Harness 如何标准化地连接和使用外部工具的问题。
- **与 [[5_Ai_Agent_部署训练项目使用]] Agent**：**Agent 是最终产物**。模型提供智能，Harness 提供可靠的执行环境，两者结合才构成一个能实际干活的 Agent。
